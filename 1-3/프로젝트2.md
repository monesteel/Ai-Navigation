[프로젝트 2] 자유 주제 자동화 설계 및 구현

## 1. 자동화할 반복 업무 정의

### 업무명
Gmail 수신 메일 자동 분류 및 알림 시스템

### 문제 상황
Monesteel 비즈니스 Gmail 계정으로 매일 다양한 메일이 수신됨:
- 국세청(@nts.go.kr)에서 오는 세무 관련 중요 메일
- 회계사무소 박정아 대리(junghwa205@nate.com)의 업무 메일
- 대량의 광고/프로모션 메일

### 기존 문제점
| 문제 | 내용 |
|------|------|
| 중요 메일 누락 | 광고 메일에 묻혀 중요 메일을 놓치는 경우 발생 |
| 수동 확인 부담 | 매일 수동으로 메일함을 확인해야 함 |
| 메일함 혼잡 | 광고 메일로 인해 메일함이 지저분해짐 |

### 자동화 목표
- 중요 메일(국세청, 회계사무소) 수신 시 Slack으로 즉시 알림
- 광고성 메일 자동 삭제(휴지통 이동)로 메일함 정리

---

## 2. 자동화 도구 선정 및 선정 이유

### 선정 도구: Zapier

### 선정 이유
| 항목 | 내용 |
|------|------|
| 노코드 | 코딩 없이 드래그&드롭으로 자동화 구현 가능 |
| Gmail 연동 | Gmail 트리거를 공식 지원 |
| Slack 연동 | Slack 알림 액션을 공식 지원 |
| 필터 기능 | Filter by Zapier로 조건 분기 처리 가능 |
| 무료 플랜 | 기본 자동화는 무료로 사용 가능 |
| 안정성 | 글로벌 기업들이 사용하는 검증된 플랫폼 |

## 3. 워크플로우 설계 문서

### 전체 구조


### Zap 1 - 국세청 메일 알림

| 단계 | 구분 | 설정 내용 |
|------|------|-----------|
| Step 1 | 트리거 | Gmail - New Email |
| Step 2 | 필터 | From Email Contains @nts.go.kr |
| Step 3 | 액션 | Slack - Send Channel Message (monesteel-전체) |

### Zap 2 - 회계사무소 메일 알림

| 단계 | 구분 | 설정 내용 |
|------|------|-----------|
| Step 1 | 트리거 | Gmail - New Email |
| Step 2 | 필터 | From Email Contains junghwa205@nate.com |
| Step 3 | 액션 | Slack - Send Channel Message (monesteel-전체) |

### Zap 3 - 광고 메일 자동 삭제

| 단계 | 구분 | 설정 내용 |
|------|------|-----------|
| Step 1 | 트리거 | Gmail - New Email |
| Step 2 | 필터 | Subject Contains 광고 OR 혜택 OR 이벤트 OR 할인 |
| Step 3 | 액션 | Gmail - Delete Email (Message ID 동적 연결) |

### 노코드 핵심 개념 적용

| 개념 | 적용 내용 |
|------|-----------|
| 트리거(Trigger) | Gmail 새 메일 수신 |
| 필터(Filter) | 발신자/제목 조건으로 분기 |
| 액션(Action) | Slack 알림 전송 / Gmail 삭제 |
| 통합(Integration) | Gmail ↔ Zapier ↔ Slack 연동 |
| 조건 분기 | 중요 메일 vs 광고 메일 구분 처리 |

## 4. 구현 화면 캡처

> 📸 **캡처 위치 안내**
> 
> **Zapier 대시보드** → 좌측 메뉴 **"Zaps"** 클릭
> → 각 Zap 클릭 → 편집 화면에서 캡처
>
> 캡처해야 할 화면:
> - Zap 1 전체 워크플로우 화면
> - Zap 2 전체 워크플로우 화면  
> - Zap 3 전체 워크플로우 화면
> - 각 Zap의 Filter 설정 화면
> - Slack 메시지 설정 화면 (Zap 1, 2)
> - Delete Email 설정 화면 (Zap 3)

## 5. 실행 결과 화면 캡처

> 📸 **캡처 위치 안내**
>
> **① Zapier 테스트 결과**
> - 각 Zap 편집 화면 → 각 Step 클릭 → **"Test"** 탭
> - "Data out" 섹션에서 실행 결과 확인
> - 초록색 체크(✅) 표시 화면 캡처
>
> **② Slack 알림 수신 결과**
> - Slack 앱 실행 → monesteel 워크스페이스
> - **#전체** 채널 클릭
> - 수신된 자동 알림 메시지 캡처
>
> **③ Gmail 삭제 결과**
> - Gmail 실행 → **휴지통(Trash)** 폴더 클릭
> - 자동 삭제된 광고 메일 확인 후 캡처
