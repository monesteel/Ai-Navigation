```plaintext
# 브랜드 아이덴티티

- 브랜드명: Kovaweb (KOVAWEB)
- 서브 카피: PREMIUM PENSION WEBSITE
- 타겟: 20~40대 가족/커플 (오션뷰 숙소와 휴식 여행을 찾는 예약 고객, 그리고 고급스러운 홈페이지가 필요한 펜션 운영자)
- 톤앤매너: 따뜻함, 잔잔함, 골든아워 자연광, 미니멀, 고급스러움, 시네마틱
- USP: "바다가 거실이 되는 오션뷰 펜션"의 감성을 담아내는 고급스럽고 세련된 펜션 전용 홈페이지
- 핵심 메시지(한 문장): "보는 순간 떠나고 싶어지는, 고급스럽고 세련된 펜션 홈페이지."
- 컬러: 네이비(#1B2A49 계열) / 골드 / 실버 + 노을 오렌지·크림 베이지(영상 톤)
- 로고: 네이비 배경용 로고(`kovaweb_logo.png`) — 골드·실버 물결 두 줄 + KOVAWEB 워드마크 + PREMIUM PENSION WEBSITE
```

| 핵심 메시지 | "보는 순간 떠나고 싶어지는, 고급스럽고 세련된 펜션 홈페이지" |

| 스토리 흐름 | 감성(노을 오션뷰) → 신뢰(고급스러운 객실) → 공감(가족의 순간) → 시작(CTA) |

## 3. 사용 도구 목록

| 구분 | 도구 | 사용 목적 | 적용 씬 |
|---|---|---|---|
| 이미지 | Google Stitch | 씬별 키비주얼(노을 펜션, 벽난로 거실, 가족 노을 장면) 생성 | 씬 1~3 |
| 이미지 | Claude | 로고 배경 제거(투명화)·합성, 장면 구성 참고용 SVG 일러스트 제작 | 씬 1~3(로고) |
| 비디오 | Claude | 정지 이미지를 코드(Python/OpenCV/ffmpeg)로 모션 클립화: 카메라 푸시인, 물결·불꽃·커튼 움직임, 빛 맥동, 로고 삽입, 씬 연결 | 씬 1~3 |
| 오디오 | GPT | 내레이션 대본 작성, 호흡 가이드, SSML, 음성 설정 제안(여성·편안한 톤·속도 90%) | 씬 1~3 |
| 오디오(BGM) | 업로드한 로파이 음원 (Echoes of Lumen) | 전체 분위기를 만드는 배경 음악. Claude(ffmpeg)로 구간 선택, 음량 -16 LUFS 정규화, 페이드 처리 | 전체 |

## 7. 프롬프트 수정 전/후 기록

### 수정 1 — 씬 1 물결 효과 범위 조정

- **수정 전 의도:** 바다와 수영장 수면을 일렁이게 해서 "살아 있는 물" 표현
- **문제:** 효과가 수영장 벽까지 번져 벽 모서리가 출렁여 보였고, 수평선 근처 섬 주변에 작은 잡티가 생김
- **수정 후 변경:** 효과 범위를 수면 안쪽으로 줄이고, 수평선 아래부터만 적용하며 흔들림 세기를 약 30% 낮춤
- **결과 변화:** 벽·건물은 고정되고 수면만 자연스럽게 움직여 사진 같은 질감 유지(섬 근처 미세 잡티 일부는 남음)

### 수정 2 — 씬 2 화면 가장자리 늘어짐

- **수정 전 의도:** 벽난로 쪽으로 이동하며 확대되는 카메라 움직임
- **문제:** 이동하면서 화면 왼쪽 끝이 이미지 밖을 비춰 가장자리가 늘어나 보임
- **수정 후 변경:** 확대 배율에 맞춰 보이는 영역이 원본 이미지 밖으로 나가지 않도록 이동 범위를 제한
- **결과 변화:** 가장자리 왜곡 제거, 이동 폭은 조금 줄었지만 벽난로로 다가가는 느낌은 유지

### 수정 3 — 로고 가독성과 내레이션 쉼

- **수정 전:** 텍스트 KOVAWEB를 흰색 글자로 삽입, 내레이션은 "보는 순간, 떠나고 싶어지는,"처럼 쉼 포함
- **문제:** 밝은 노을 하늘·주황 커튼 위에서 글자 대비가 약했고, 짧은 씬에 쉼이 많아 호흡이 끊김
- **수정 후 변경:** 업로드한 공식 로고로 교체하고 로고 뒤에 어두운 번짐을 추가, 내레이션은 쉼 없이 씬당 한 문장으로 변경
- **결과 변화:** 3개 씬 모두에서 로고가 읽히고, 씬 길이에 맞는 안정적인 내레이션 흐름 확보
